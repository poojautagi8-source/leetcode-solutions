# Problem: Move Zeroes (Easy)

**Link:** https://leetcode.com/problems/move-zeroes/

## Approach

I moved all non-zero values toward the beginning of the array while maintaining their original order. After processing the non-zero values, the remaining positions were filled with zeroes.

## Complexity

- Time: O(n)
- Space: O(1)

## Notes

The operation is performed in-place. The relative order of non-zero elements must remain unchanged.
