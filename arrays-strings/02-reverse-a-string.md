# Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

## Approach

I used the two-pointer technique. One pointer starts from the beginning and another from the end, and the characters are swapped until the pointers meet.

## Complexity

- Time: O(n)
- Space: O(1)

## Notes

The string is modified in-place, so no separate string is required. A single-character string is already reversed.
